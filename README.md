# Koma-African-Food
KOMA African Food" with the following features:

Multi-page frontend with pages: Home, Menu (with cart functionality), Cart (order submission), About Us, Contact.
Backend server using Node.js and Express to serve static pages and handle orders via API.
Full styling in a separate CSS file.
Frontend JavaScript for menu loading, cart management, and order submission.
Instructions for setting up the project locally, running the server, and pushing to GitHub.
